# Parth Kaklotar — Portfolio

This repository hosts my personal portfolio built with HTML, CSS and JavaScript.

**Live:** https://parthkp126.github.io

## How to run locally
1. Clone: git clone https://github.com/parthkp126/parthkp126.github.io.git
2. cd parthkp126.github.io
3. python -m http.server 8000
4. Open http://localhost:8000
